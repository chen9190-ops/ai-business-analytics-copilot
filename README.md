# AI Business Analytics Copilot

LLM-powered AI analytics agent system for automated business analysis, dynamic schema reasoning, intelligent tool routing, and AI-generated business insights.

Built with OpenAI, Streamlit, Scikit-learn, and modular AI-agent architecture.

---

# Core AI Features

## LLM Agent Orchestration
- AI-powered business question routing
- Context-aware analytical workflow execution
- Multi-tool agent orchestration
- Automated analytical decision making

## Dynamic Schema Reasoning
- Automatic dataframe understanding using LLMs
- Dynamic column detection across heterogeneous datasets
- AI-driven semantic mapping for:
  - revenue fields
  - customer identifiers
  - product dimensions
  - date/time structures
  - regional hierarchies

## AI Insight Generation
- Automated business insight summarization
- LLM-generated strategic recommendations
- Context-aware analytical interpretation
- Natural language business reporting

## AI-Driven Analytics Automation
- Natural language → analytical workflow execution
- Automated business KPI generation
- Intelligent analytical pipeline selection
- End-to-end AI-assisted analytics workflow
